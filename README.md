# MA

轻量级双窗口文件管理器，灵感来自 [MT管理器](https://mt.cc)，基于 MT Manager 2.26.11 反编译分析后的重写实现。

使用 **Jetpack Compose** + **Kotlin** 构建，优先支持 Root 与 Shizuku。

> **范围声明**：本项目**完全不包含 APK 逆向修改功能**（无 dex / arsc 编辑、无 smali 反编译修改、无重新打包与签名、无资源注入）。APK 相关能力仅限**只读信息查看**与**系统安装器调用**。

## 功能

### 双窗口文件管理
- 左右独立面板，点击/长按切换活动窗口
- **阴影跟随活动窗口镜像**（对齐 MT 管理器）：中心竖线、工具栏下沿、底栏上沿
  三条边阴影一律投在**非活动视窗**一侧，活动视窗保持纯白；切换活动窗口时整体镜像
  - 左视窗活动 → 中心竖线阴影在中心线**右**侧，顶部/底部横阴影只画**右**半
  - 右视窗活动 → 中心竖线阴影在中心线**左**侧，顶部/底部横阴影只画**左**半
- **多选选中态**（对齐 MT）：整行纯色高亮（浅色 `#66BFDF`），**不显示勾选图标**
- 顶部标题栏显示当前活动窗口的路径与「文件夹 / 文件」统计
- 导航：后退 / 前进 / 上级 / 路径跳转 / 窗口同步 / 历史栈
- 每个窗口独立维护路径历史与排序

### 排序与显示
- 排序方式：名称 / 大小 / 修改时间 / 类型，支持升序降序
- 文件夹优先显示开关
- 显示 / 隐藏隐藏文件（`.` 开头）
- 按类型着色图标：文件夹、压缩包、APK、图片、视频、音频、文本、代码
- 显示修改时间、大小与权限位（Root/Shell 场景）

### 文件操作
- 复制 / 剪切 / 粘贴，粘贴时**冲突解决**（覆盖 / 跳过 / 保留两者）
- 多选（点击已选状态切换、全选、反选）、批量删除
- 重命名、批量重命名（查找替换，保留扩展名）
- 新建文件 / 文件夹
- chmod 权限修改（需 Root）
- **回收站**：删除默认移入 `/storage/emulated/0/.MA_Trash`，可清空
- 属性对话框：名称 / 路径 / 类型 / 大小 / 时间 / 权限 / APK 摘要

### 长按菜单与 APK 安装（对齐 MT 2.26.11）
- **方向箭头跟随源窗口**：长按左视窗文件 → `复制 ->` / `添加 ->` / `移动 ->`（向右）；
  长按右视窗文件 → `复制 <-` / `添加 <-` / `移动 <-`（向左）；三项统一镜像
- **复制 / 添加按目标窗口区分**：另一侧是普通目录 → 「复制」+ 复制图标；
  另一侧是 `zip://` 压缩包预览 → 「添加」+ 加号图标
- 长按菜单：普通 `.apk` 与 `.apks/.xapk/.apkm` 一样提供**安装**；`APK 信息` 与实际打开的对话框一致
- 文案对齐 MT 中文资源：`打开方式…`、`解压到…`、`APK 信息`
- **安装前二次确认**：长按「安装」先展示应用名 / 包名 / 版本 / 签名摘要，确认后才安装
- **安装前验证签名和版本号**：签名不一致 / 降级安装 / SDK 不兼容时直接阻止（fail-fast），文案对齐 MT
- **覆盖安装**：已安装同包名应用时仍可更新，需通过「是否覆盖安装？」二次确认

### 搜索
- 当前目录递归搜索（深度 12）
- 可按文件名匹配，或同时搜索文本文件内容（≤1MB）

### 压缩与解压
- 浏览 zip / apk / jar 内部（只读）
- 从选中项创建压缩包（可选密码）
- 向已有压缩包添加文件
- 解压整个压缩包或单个条目到指定目录
- 压缩包完整性测试
- 进度显示与取消

### 查看器与编辑器
- **文本编辑器全面对齐 MT 2.26.11**（按编辑器截图像素采样）：
  - 图标栏均匀分布、图钉倾斜 45°、撤销/重做按历史栈置灰；图标栏与信息行间有细分隔线
  - 信息行 `文件名 · 行:列 · 编码`，编码浅灰字（不再蓝色），位置信息靠右
  - **行号槽**：浅灰底 `#F8F8F8` + 右侧 `#E6E6E6` 竖线 + 连续行号；**去掉代码折叠标记与预览文字**
  - **当前行浅黄高亮** `#FDFAE5`、自动换行箭头 `↵` / 续行折角 `⌞`、缩进参考竖线
  - **语法配色**：关键字深藏青 `#13306A`、字符串绿 `#187028`、注释灰 `#8C8C8C` 斜体
  - 菜单新增：保存并退出 / 转到指定行 / 指定编码重新加载 / 语法高亮 / 只读模式 / 重新加载文件 / 关闭文件，
    以及显示行号信息、显示自动换行箭头、显示缩进参考线、等宽字体开关（均有真实状态支撑）
- 查找 / 替换全部、只读模式、自动换行、字号调整
- 图片查看器（BitmapFactory 解码，只读）
- 十六进制查看器：分页浏览、偏移显示（只读）

### APK 工具（只读）
- APK 信息查看：包名 / 版本 / SDK / 大小 / 组件数量 / 签名 SHA-256、SHA-1、MD5 / 权限列表 / 安装时间
- 安装包提取：列出已安装应用并导出 APK 到 Download/MA-APK
- 调用系统安装器安装 APK

### 书签
- JSON 持久化（应用私有目录）
- 侧边栏直接跳转、删除，支持分组字段
- 独立书签管理页面

### 终端
- libsu shell 执行，命令历史快捷条（最近 10 条）、回车执行、清空输出

### 设置
- 主题：跟随系统 / 浅色 / 深色
- 显示隐藏文件、文件夹优先、默认排序、默认路径
- 回收站开关、删除前确认、编辑器自动换行
- Root / Shell 状态显示

### 全局动画（本轮新增）
- 规格集中在 `ui/theme/MAAnim.kt`：微反馈 **160ms**、页面切换 **220ms**；改一处即全局生效，两个常量置 0 即关闭动画
- 页面切换：`MainScreen` 用 `AnimatedContent` 统一驱动，列表 ↔ 设置 / 书签 / 终端 / 回收站 / 编辑器 / APK / 图片 / Hex / 媒体 / 文本编辑器 全部有进出过渡；进入全屏页从右滑入淡入、旧列表轻微左移淡出，返回时反向
- 状态变化：活动窗口阴影镜像（`Crossfade`）、多选选中行背景渐变、Snackbar 下方滑入、长按菜单淡入放大、操作进度条平滑
- 抽屉、`DropdownMenu`、`AlertDialog` 沿用 Material 3 自带动画
- **明确不加**：列表滚动 / 缩略图加载 / 编辑器 Canvas 绘制（会掉帧或破坏 offset 映射）

## 技术栈

- Kotlin 2.0 + Jetpack Compose（Material 3）
- libsu (Root) / Shizuku API
- Zip4j（压缩包）
- SharedPreferences（设置）+ JSON 文件（书签）
- 仅编译 `arm64-v8a`

## 构建

工具链：**AGP 8.7.3** / Kotlin 2.0.21 / Gradle 8.9 / JDK 17 / compileSdk 35。

> AGP 8.7.0～8.7.2 的 lint 会在 release 构建时打印大量
> `WARNING: Missing analysis API method ... Ka*` 警告（Google Issue #374488858，
> lint 与 Kotlin Analysis API 版本错配）。**8.7.3 已修复**；该警告是工具链噪声，
> 不影响编译产物。Compose 状态动画统一使用 `androidx.compose.animation.core` 包下的
> `animateFloatAsState` / `animateDpAsState`，`animateColorAsState` 在
> `androidx.compose.animation` 包下，两者不要混用。

```bash
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`。
